# Lingua Franca 使用教程

> 适用：Minecraft 26.3 · Fabric · 公开测试版 Beta 0.0.1

## 1. 准备

| 需要 | 说明 |
|---|---|
| Minecraft 26.3 | 正版/离线均可，版本号必须是 26.3 |
| Fabric Loader | 0.20.1 或更新 |
| Fabric API | 与 26.3 对应版本，放 mods |
| Java | 25 或更新（Fabric 26.3 要求） |
| 翻译 API Key | 默认 DeepSeek，可换兼容 OpenAI 格式的服务 |

## 2. 安装

1. 关闭游戏；
2. 把 `lingua-franca-0.0.1.jar` 放入 `mods` 文件夹；
3. 确认 `mods` 里只有一个 `lingua-franca-*.jar`（旧版本请删除）；
4. 启动游戏，进入任意世界或服务器。

## 3. 配置翻译服务

### 方式 A：游戏内设置

按 **J** 打开设置界面 → 填入 API Key → 保存。

### 方式 B：配置文件

路径：`config/lingua-franca.json`

```json
{
  "enabled": true,
  "apiKey": "你的Key",
  "baseUrl": "https://api.deepseek.com",
  "model": "deepseek-flash",
  "translateChat": true,
  "translateTooltip": true,
  "translateItemName": true,
  "translateItemLore": true,
  "translateTextDisplay": true,
  "translateAdvancements": true,
  "translateSigns": true,
  "translateTabList": true,
  "translateBossBar": true,
  "tabBossServers": "wynncraft",
  "useDefaultFontForChinese": true,
  "maxCache": 200000
}
```

> 默认模型 `deepseek-flash`。如使用其它服务，修改 `baseUrl` / `model` / `apiKey` 即可。

## 4. 各模块开关说明

| 配置 | 默认 | 说明 |
|---|---|---|
| translateChat | 开 | 聊天消息 |
| translateTooltip | 开 | 悬停提示 |
| translateItemName / translateItemLore | 开 | 物品名称 / 描述 |
| translateTextDisplay | 开 | 世界内浮空字 |
| translateAdvancements | 开 | 成就 |
| translateSigns | 开 | 木牌 |
| translateTabList | 开 | Tab 列表（默认仅 Wynncraft） |
| translateBossBar | 开 | Boss 条（默认仅 Wynncraft） |
| tabBossServers | wynncraft | Tab/Boss 条生效的服务器关键字，可填多个用逗号分隔 |
| protectedNames | 空 | 不翻译的名字（如固定 NPC 名） |

## 5. 缓存与词表

| 位置 | 内容 |
|---|---|
| `config/cache/translations-server-<服务器>.tsv` | 分服翻译缓存（自动生成） |
| `config/lingua-franca-glossary.tsv` | 当前词表（可手工追加） |
| 模组内置词表 | 游戏通用文本的初始翻译 |

- 翻过的文本会写入缓存，下次直接显示中文，**不会重复消耗额度**；
- 想清空某个服的缓存：关闭游戏后删除对应的 `translations-server-*.tsv`；
- 想贡献词表：用 `tools/export_glossary.py` 导出后提交到仓库。

## 6. 性能建议

- 模组已按来源拆分请求队列，正常游玩无需额外设置；
- 如果遇到卡顿，可在配置里打开 `"debugMetrics": true`，日志每 30 秒打印各队列排队情况，把日志发给开发者定位。

## 7. 常见问题

**没有翻译**
- 检查 `mods` 里是否只有一份模组；
- 检查 API Key 是否有效、网络是否可达 `baseUrl`；
- 日志里应有 `[lingua] ready: ...`。

**部分文本仍是英文**
- 该文本可能由第三方模组自绘（如 Wynntils），模组会自动跳过；
- 也可能是服务器用了特殊字体。

**想临时关闭**：按 J 关闭总开关，或把 `enabled` 改为 `false`。

**更新模组**：删除旧 jar，放入新 jar；配置与缓存会保留。

**卸载**：删除 jar；需要的话再删除 `config/lingua-franca*`。
