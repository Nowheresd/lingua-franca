# Modrinth 发布文案

## 简介（中文）

把服务器里的英文实时翻译成中文。支持聊天、物品与 Lore、悬停提示、浮空字、木牌、成就、记分板、Tab、Boss 条和 Wynncraft NPC 对话；本地缓存让同一句话只翻译一次。

公开测试版 Beta 0.0.1，需要自备翻译服务 API Key（默认 DeepSeek，可换兼容服务）。

---

## 正文（中文长描述）

**Lingua Franca** 是一个 Minecraft 26.3（Fabric）的**纯客户端**翻译模组：它不修改资源包、不改服务器数据，只把客户端"显示出来的文字"实时替换成中文。

### 功能
- 💬 聊天消息
- 🪧 物品名称与 Lore、悬停提示
- 🏷️ 世界浮空字、木牌
- 🏆 成就名称与描述
- 📊 Tab 列表、计分板、Boss 条、动作栏
- 🗣️ Wynncraft NPC 对话（名字 / 正文 / 选项）
- 🧠 分服本地缓存：翻过的文本立即复用，节省额度

### 安装
1. 安装 Fabric Loader（26.3）与 Fabric API
2. 把 jar 放入 mods
3. 启动游戏，按 **J** 打开设置，填入 API Key

### 说明
- 纯客户端，无需服务器安装
- 默认模型 deepseek-flash，可自定义服务地址与模型
- 公开测试版，欢迎反馈问题

## Short description (EN)

Real-time Chinese translation for English server text in Minecraft 26.3: chat, items and lore, tooltips, holograms, signs, advancements, tab list, scoreboard, boss bars and Wynncraft NPC dialogue. Client-side only, with a per-server cache. Public beta 0.0.1 — bring your own translation API key (DeepSeek by default; any OpenAI-compatible service works).

## Long description (EN)

**Lingua Franca** is a **client-side Fabric mod for Minecraft 26.3** that translates English server text into Chinese in real time without touching resource packs or server data.

Features:
- Chat messages
- Item names and lore, hover tooltips
- Holograms and signs
- Advancements
- Tab list, scoreboard, boss bars, action bar
- Wynncraft NPC dialogue (name / body / choices)
- Per-server local cache: each phrase is translated once and reused

Install: Fabric Loader (26.3) + Fabric API, drop the jar into `mods`, press **J**, enter your API key.

Notes:
- Client-side only
- Default model: deepseek-flash; custom endpoints/models supported
- Public beta — feedback welcome
